# مهندس المجلس | Majlis Engineer

تطبيق Android أصلي لإدارة مشاريع المجالس وأعمال البناء والتشطيبات، بواجهة عربية واتجاه RTL، مع حفظ محلي يعمل دون اتصال.

## الوظائف الموجودة في التطبيق
- لوحة متابعة ومشاريع متعددة، مع بيانات العميل والموقع ونوع المشروع وحالة التنفيذ.
- معاينة ميدانية لكل فراغ: الطول والعرض والارتفاع ومساحة الفتحات، وحساب مساحات الأرضيات والجدران.
- جدول كميات وتسعير بالريال العماني (3 منازل عشرية) مع إجماليات تلقائية.
- مهام تنفيذ وتحديث حالة كل مهمة.
- سجل ملاحظات فنية مصنف حسب طبقات المعماري والكهرباء والسباكة والصرف والتكييف والتشطيبات والأثاث.
- مكتبة مواد محلية قابلة للبحث وإضافة مواد وتصنيفات.
- تقرير مشروع PDF قابل للحفظ من نافذة إنشاء الملفات في Android.
- قاعدة بيانات Room محلية مع ترحيل من إصدار قاعدة البيانات السابق دون حذف بيانات المواد.

## البناء والاختبار
يتحقق GitHub Actions من اختبارات JVM، ويبني APK، ويشغّل اختبار رحلة أساسية على محاكي Android API 35، ثم يحفظ APK كـ Artifact.

## الحدود الهندسية
سجل الطبقات الحالي مخصص للملاحظات الفنية، وليس محرر CAD. استيراد/تحرير/تصدير DWG أو DXF، والرسم المتجهي التنفيذي، والمزامنة السحابية، والأسعار السوقية الحية ليست وظائف مدعاة في هذه النسخة. يجب مراجعة القياسات والمخرجات من مهندس مختص قبل استخدامها للتنفيذ.
