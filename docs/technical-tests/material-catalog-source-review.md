# مراجعة مصادر كتالوج مواد البناء في عُمان

**التاريخ:** 2026-11-14  
**الغرض:** تحديد ما إذا كان هناك كتالوج شامل قابل لإعادة الاستخدام داخل التطبيق، وعدم استيراد أسعار أو بيانات موردين دون سند.

## ما أمكن التحقق منه

- تعرض صفحة Trident National Enterprise في عُمان مجموعات لمواد البناء، منها الأسمنت، المنتجات الكهربائية، الإضاءة، الدهانات، وصلات أنابيب PPR، الأدوات، مستلزمات السباكة، الجبس، الخشب، المواد الكيميائية، والعزل المائي. الصفحة وصفٌ لفئات الشركة وصورها وليست ملفًا موحدًا قابلًا للتنزيل يحوي سجلّات منتجات وأسعار كاملة.
- تعرض EInfraSouq نفسها كسوق B2B عُماني لموردي مواد البناء، وتوضح أن السعر الظاهر يحدده المورد. لم يُعثر في الصفحات العامة التي روجعت على تصدير شامل مفتوح أو واجهة API عامة لقاعدة منتجات السوق؛ لا نفترض توفر إذن أو تكامل غير معلن.
- صفحة كتالوجات Mamlkah Home تربط تصنيفات مثل مواد التأسيس والهيكل والتشطيب وما بعد البناء والمعدات. شروطها المنشورة تحمي نصوص الموقع وصوره وبياناته، وتقصر التنزيل على استخدام شخصي غير تجاري، وتحظر الاستخدام التجاري أو إعادة التوزيع دون إذن كتابي مسبق؛ لذلك لا ننسخ أصنافها أو صورها أو أسعارها إلى كتالوج التطبيق.
- واجهة Sterling المنشورة عبر Publitas تعرض 139 صفحة وتقترح خيار تنزيل PDF، لكن المحتوى لم يكن قابلًا للاستخراج في المراجعة ولم يُتحقق من ترخيص إعادة استخدامه؛ لم تُستورد بيانات منها.

## قرار التطبيق

لا يظهر في المصادر العامة التي تمت مراجعتها سجل موحد ومفتوح يجمع كل منتجات السوق العُماني ومواصفاتها وأسعارها. لذلك يضم التطبيق **كتالوجًا محليًا عامًا مُعدًّا مسبقًا** لأصناف مواد المجالس والتشطيبات، لا أسماء/صور/أسعار مورد بعينه. تُستورد المواد تلقائيًا إلى Room من ملف الأصول، وتبقى متاحة دون إنترنت. تظل العلامة التجارية والسعر فارغين/غير محددين إلى أن يسجل المستخدم عرض مورد مؤرخًا؛ السعر الأساسي صفر داخليًا للتوافق مع المخطط القديم فقط ولا يجوز عرضه على أنه سعر مجاني أو تكلفة صفر.
